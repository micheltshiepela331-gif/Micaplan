# Micaplan

Une application de conception de plans en français, utilisable sur ordinateur, tablette et téléphone Android depuis un navigateur moderne.

## Démarrer

Ouvrir `index.html` dans un navigateur. Aucun paquet ni serveur n'est nécessaire pour le dessin de base.

## Fonctionnalités actuelles

- Dessin de murs, lignes, rectangles et cercles ; sélection et suppression.
- Zoom à la molette, aux boutons +/− ou par pincement tactile, avec zoom centré sur le pointeur et limites de sécurité.
- Déplacement du plan à la souris (bouton droit ou Espace + glisser) et au toucher.
- Grille, aimant, annulation et rétablissement.
- Sauvegarde locale dans le navigateur, plus import/export d'une copie JSON.
- Interface responsive pensée pour PC, tablette et Android ; le mode portrait reste utilisable.

Les plans enregistrés localement restent sur le même navigateur et le même appareil. Exportez régulièrement un fichier JSON pour en conserver une copie. Cette première version est une base stable ; elle ne reprend pas encore toutes les fonctions avancées de Lushi-plan (3D, cotations, calques, portes/fenêtres, etc.).
